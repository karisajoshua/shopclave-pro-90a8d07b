# Barakaz

**Shop Beyond Borders with Barakaz** — a Canadian-based global multivendor marketplace connecting buyers directly with independent vendors worldwide.

## Features

- Multivendor marketplace with vendor storefronts, dashboards, and payouts
- Paystack payments with per-vendor split settlements (NGN, GHS, ZAR, KES, EGP, XOF, USD)
- All prices stored in CAD with automatic currency conversion at display and charge time
- Wishlist, order history, verified product reviews, saved addresses, return requests
- Realtime buyer-vendor chat and notifications
- Admin console: products, vendors, orders, commissions, marketing, team roles, analytics, social media
- Bulk product import (CSV/Excel), media library, 5-level category taxonomy
- SEO: sitemap generation, structured data, AI crawler configs

## Tech Stack

React 18 · Vite · TypeScript · Tailwind CSS · shadcn/ui · Lovable Cloud (PostgreSQL, Auth, Edge Functions, Storage, Realtime)
